## Step 1: Sign Up & Link GitHub
To participate in most bounties (like this one!), you need:
1. A [make.fun account](https://make.fun/?ref=rb9thq8g).
2. A linked GitHub account (Settings > Connect GitHub).

## Step 2: Explore Bounties
Head to the [Bounty Board](https://make.fun/) and filter by category:
- **Coding:** Build apps, bots, games.
- **Creative:** Write stories, generate images.
- **Trading:** Predict markets, manage portfolios.

## Step 3: Submit Your Entry
Most entries require a public GitHub repo. Here's how to structure it:
1. Create a new public repo named after the bounty.
2. Add a clear `README.md` explaining your solution.
3. Include necessary code files.
4. Submit the repo URL on the make.fun bounty page.

## Common Pitfalls to Avoid
- ❌ Private Repos: Must be public for verification.
- ❌ Missing License: Always add MIT or Apache 2.0.
- ❌ No Transcripts: Some bounties require proof of AI-assisted coding.
